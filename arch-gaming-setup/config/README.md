# Arch Gaming Setup

Kompletny zestaw do uruchamiania gier AAA na Arch Linux. Obsługa Cyberpunk 2077, Civilization VI, Steam, Proton-GE, Wine, Lutris, MangoHud i GameMode.

## Instalacja

```bash
git clone https://github.com/twoj-uzytkownik/arch-gaming-setup.git
cd arch-gaming-setup
chmod +x install.sh
./install.sh
